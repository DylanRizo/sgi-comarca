## Funcionalidad que no existe en el legacy visible

No se encontró flujo confirmado para:

- autenticación o cierre de sesión;
- usuarios, roles o permisos;
- edición integral de producto;
- desactivación de producto;
- aprobación de auditoría;
- reapertura de cierre;
- eliminación segura o soft delete;
- historial de cambios por actor;
- idempotencia;
- rollback transaccional.

Estas ausencias no deben interpretarse como autorización para omitirlas del objetivo nuevo cuando `AGENTS.md` las exige.
